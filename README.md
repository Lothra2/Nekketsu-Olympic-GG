# Nekketsu Olympic GG

Remake espiritual de los juegos deportivos Nekketsu de NES/Famicom: cross country callejero, carrera de obstáculos, tama-wari, natación sin reglas y una batalla final en la azotea. Los personajes, el mundo, los efectos, la interfaz y el audio salen de [PixelForja](https://github.com/Lothra2/pixel_forja).

Estado: planificación. El plan completo está en [docs/PLAN.md](docs/PLAN.md).
